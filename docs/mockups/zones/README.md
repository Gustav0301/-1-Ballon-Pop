# Sky zone layers plan (2026-10-09)

Live page: https://claude.ai/artifact/DKq6G3o433RCYp4JgWfAaV. You can also open `index.html` here in a browser.

The plan covers all 8 zones. Each zone lists its sky colours (hex), its far, middle and near layers, what you see below you, the transition to the next zone, a sound mood, the weather on top and one "wow moment".

The recommended build order starts with Meadow Sky, Cloud Shelf and the jump between them.
