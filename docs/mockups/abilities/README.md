# Balloon abilities preview (2026-10-09)

Live page: https://claude.ai/artifact/8gxAmxacnn3xbiBtyazvMP. You can also open `index.html` here in a browser.

The page uses the real balloon models from `BalloonModels.lua`. The pictures are `preview.png`, `moments-1.png` and `moments-2.png`.

Every ability has a name, an icon, a description and its effect. Find them in `index.html`:
- `AB` holds the name, description, cooldown and key.
- `DEF.<Balloon>` holds the effect.

Big powers use the ability key: Frost, Clock and Whale on **Q**, and Iron on **Space** (letting out air). All the others are automatic. The page can also show everything automatic.

Stand-ins for powers whose systems don't exist yet:

| Balloon | Stand-in now | Real power later |
|---|---|---|
| Ember | +10% coins, all the time | Brighter at night |
| Volt | Static charge, then +25% coins when you land | Lightning |
| Sun | Scorches birds that come too close | Melts hail and meteors |
| Crown | A gold shield bounces a hit back | Pins |
